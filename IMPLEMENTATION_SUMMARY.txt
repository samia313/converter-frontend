HOW IT WORKS NOW
================================================================================

USER FLOW:
1. User visits /compress-pdf (or any other tool)
2. User uploads a PDF file
3. "Process File" button becomes enabled
4. User clicks "Process File"
5. File is sent to /api/convert/compress-pdf
6. API processes the file using pdf-lib
7. Processed file is returned
8. "Download PDF" button appears
9. User clicks to download the converted file

FILE PROCESSING PIPELINE:
┌─────────────────┐
│  Upload File    │ User selects file
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  FileUploader   │ Component displays file
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ Process Button  │ User clicks Process
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  API Route      │ /api/convert/{tool}
│ (pdf-lib)       │ Processes file
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ Download Link   │ File available
└─────────────────┘
