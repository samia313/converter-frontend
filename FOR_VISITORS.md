## How to Use Any Tool - 4 Simple Steps

### Step 1: Go to the Tool Page
Pick any of the 8 tools above and visit that link.

### Step 2: Upload Your File
You'll see a "Drop your files here" box at the top of the page.

You can either:
- **Drag and drop** your file directly into the box, OR
- **Click "or click to browse"** to select a file from your computer

### Step 3: Click Convert
After selecting your file, a "Convert" or "Process" button will appear.

Click it to start the conversion.

You'll see "Converting..." while the process runs (usually 1-5 seconds).

### Step 4: Download Your File
Once complete, your converted file downloads automatically.

If it doesn't, click the download button that appears.

Your file is now ready to use!

## Troubleshooting

### "Upload area not visible"
**Solution:** Scroll to the very top of the page. The upload box is at the top!

### "File didn't convert"
**Solution:** Check that:
1. You uploaded the correct file type (PDF, DOCX, etc.)
2. You clicked the Convert button (not just uploaded)
3. You waited for "Converting..." to complete
4. File size is less than 50MB

### "Download didn't start"
**Solution:**
1. Check your Downloads folder
2. Check browser notifications
3. Try uploading again
4. Try a different file

### "Error message appeared"
**Solution:** The error message explains what's wrong:
- File type not supported? → Use correct file format
- File too large? → Try a smaller file
- Wrong number of files? → Merge PDF needs 2+ files

## Tips for Best Results

1. **Use clear file names** - Makes it easier to find later
2. **Check file before uploading** - Ensure it's not corrupted
3. **Use newest versions** - DOCX instead of DOC, modern PDFs
4. **One file at a time** - Unless tool specifically allows multiple
5. **Keep files simple** - Removes unnecessary formatting
