## Content strategy
- Use the dedicated tool page for the broad commercial query.
- Use guides for specific informational intent.
- Link each guide to its primary tool and closely related guides.
- Avoid creating multiple pages for the same search intent.
- Expand clusters only when a genuinely different user question exists.
